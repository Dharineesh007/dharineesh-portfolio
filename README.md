## Run Locally

### Prerequisites
- Node.js 18 or newer
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Dharineesh007/dharineesh-portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd dharineesh-portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the localhost URL displayed in your terminal.

## Production Build

```bash
npm run build
npm run preview
```

The production-ready files will be generated inside the `dist` directory.

## Deployment

This portfolio can be deployed for free using:

- [Vercel](https://vercel.com/)
- [Netlify](https://www.netlify.com/)

For Vercel, import the GitHub repository and use:

- Framework: Vite
