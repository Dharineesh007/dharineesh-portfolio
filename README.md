# Dharineesh S S — Personal Portfolio

Dark, responsive portfolio built with React, Vite, and Tailwind CSS.

## Run locally
1. Install Node.js 18 or newer.
2. Extract this ZIP and open the folder in VS Code.
3. Run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the localhost URL shown in the terminal.

## Production build
```bash
npm run build
npm run preview
```

## Free deployment
### Vercel
1. Push the project to a GitHub repository.
2. Import the repository in Vercel.
3. Select Vite, build command `npm run build`, output directory `dist`.
4. Deploy.

### Netlify
1. Import the GitHub repository in Netlify.
2. Build command: `npm run build`.
3. Publish directory: `dist`.
4. Deploy.

## Accuracy
All portfolio content is based on the resume text supplied by the user. No project links or additional achievements have been invented.
